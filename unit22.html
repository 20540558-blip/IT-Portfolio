UNIT 22 — Computer Security in Practice

Computer Security

This unit focused on protecting computer systems, networks and data against cyber threats. I learned how to identify security risks, implement security controls and evaluate the effectiveness of different security measures used by organisations.

Download Work

Unit Overview

During this unit I explored how organisations protect their IT systems from cyber threats. I learned about different types of malware, security policies, authentication methods, encryption, network security and how security measures are implemented in real-world environments.

What I Learned

Threat Identification

Identified common cyber threats including malware, phishing, ransomware and social engineering attacks.

Network Security

Learned how firewalls, intrusion detection systems and secure network configurations help protect organisations.

Authentication

Explored password policies, Multi-Factor Authentication (MFA), user permissions and access control methods.

Data Protection

Studied encryption, secure backups and disaster recovery strategies used to protect sensitive information.

Challenges

One of the biggest challenges was understanding how different security controls work together to protect systems. Through research and practical activities I developed a stronger understanding of cybersecurity best practices.
