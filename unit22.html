UNIT 22 — COMPUTER SECURITY IN PRACTICE

Computer Security

This unit focused on protecting computer systems, networks and data against cyber threats. I explored security risks, implemented security controls and evaluated different methods used to protect modern organisations.

Download Work

Unit Overview

During this unit I explored how organisations protect their IT systems from cyber threats. I learned about malware, phishing, authentication methods, encryption, firewalls, network security, security policies and practical techniques used to secure digital systems.

What I Learned

Threat Identification

Identified common cyber threats including malware, phishing, ransomware and social engineering attacks.

Network Security

Learned how firewalls, intrusion detection systems and secure network configurations protect organisations from cyber attacks.

Authentication

Explored password policies, Multi-Factor Authentication (MFA), user permissions and access control methods.

Data Protection

Studied encryption, secure backups and disaster recovery strategies used to protect sensitive information.

Challenges

One of the biggest challenges was understanding how different security controls work together to protect systems. Through research, practical activities and testing I developed a much stronger understanding of cybersecurity best practices.
