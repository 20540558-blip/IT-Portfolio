UNIT 22 — SOFTWARE DEVELOPMENT

Software Development

This unit focused on designing, developing and testing software solutions to meet user requirements. It strengthened my programming, problem-solving and software development skills through practical projects.

Download Work

Unit Overview

During this unit I followed the software development life cycle to plan, create and evaluate software solutions. I learned how to analyse requirements, design algorithms, write code, test programs and improve them through evaluation.

What I Learned

Planning

Created designs, algorithms and flowcharts before writing code.

Programming

Developed software using programming concepts including variables, selection, iteration and functions.

Testing

Tested programs to identify and fix logical and syntax errors.

Evaluation

Reviewed completed solutions and suggested improvements for future development.

Challenges

One of the biggest challenges was breaking larger problems into smaller tasks and debugging errors. Through testing and practice I became more confident creating reliable programs.
