Bank Account Simulator

After completing the Student Grade Manager, I developed a more advanced console-based Python application called the Bank Account Simulator. This project allowed me to build on my existing Python knowledge by introducing user authentication, account management and transaction tracking. The application uses nested dictionaries to securely store account information and demonstrates my ability to organise larger programs using reusable functions.

Main Menu

The main menu acts as the navigation system for the application. It allows users to log in, create a new account, deposit money, withdraw money, transfer funds, change their PIN, view their balance, review transaction history and delete their account. Creating this menu strengthened my understanding of conditional statements, loops and function-based program design.

Create Account

The Create Account feature allows users to register a new bank account by entering a unique username and creating a secure four-digit PIN. Each account is stored inside a nested Python dictionary containing the user's balance, transaction history and PIN. Input validation prevents duplicate usernames from being created and ensures that PINs meet the required format. Developing this feature improved my understanding of nested dictionaries, user input validation and data organisation.

View Balance & Deposit

Once logged in, users can securely deposit money into their account and immediately view their updated balance. Every deposit is automatically recorded in the transaction history, allowing all account activity to be tracked. This feature strengthened my understanding of updating nested dictionaries, storing information in lists and using functions to modify and display data accurately.
